# Number Guessing Game — Step 1

## Run your program

Double-click RunGame.cmd. A console window should display:

Welcome to the number guessing game!

Press any key when you are ready to close the window.

You can also open a terminal in this folder and enter:

dotnet run

## Your first code

Open Program.cs in your code editor. This is the file you will change as you learn.

- The line starting with // is a comment: a note for the reader that does not run.
- Console.WriteLine displays a line of text.
- The text inside quotation marks is a string.
- The semicolon ends the instruction.

Try changing the welcome message, save Program.cs, and run the game again.

NumberGuessingGame.csproj holds project settings. You do not need to edit it for this lesson.
